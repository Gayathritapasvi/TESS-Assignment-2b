# Results

Results were generated on the corrected 2,800-file TESS archive with a stratified 70/15/15 split (seed 42), CPU training, validation-loss checkpoint selection, and 420 held-out test recordings. See `comparison.md` for the summary and `../report.md` for interpretation and actual error cases. Per-model folders contain checkpoints, split manifests, metrics, confusion counts, and misclassified examples. `plots/` contains confusion matrices and held-out representation t-SNE plots.
